# Giro Infinito — GiroLab

Sitio estático para generar ideas y guiones para Shorts del canal de YouTube Giro Infinito. Usa `index.html`, `styles.css` y `app.js`; no necesita paquetes ni compilación.

## Sitio publicado

https://manubasualto140904-lab.github.io/giro-infinito/

## Publicar cambios

En el repositorio `manubasualto140904-lab/giro-infinito`, configura **Settings → Pages → Deploy from a branch → main → /(root)**. GitHub Pages publicará la raíz de `main` y actualizará el sitio cuando se suban cambios a esa rama.

Los favoritos de GiroLab se guardan solo en el navegador de cada visitante.
